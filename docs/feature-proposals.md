# 新機能提案一覧

> 作成日：2026-03-11  
> 対象プロジェクト：AI広告画像ジェネレーター

ユーザー価値・収益・技術的実現可能性の3軸で評価した新機能の提案。

---

## 🔥 優先度：高（リリース直後に実装すべき）

### 1. 一括生成（バリエーション生成）

**概要**  
同じ広告を複数のサイズ・テイストで一度に生成する機能。

**詳細**  
例：Instagram正方形・Stories・Xバナーを1クリックで同時生成。出力結果はZIPでのダウンロードにも対応。

**期待効果**  
- ユーザーが最も困っている「フォーマットごとに何度も設定し直す手間」を解消
- 1操作あたりのクレジット消費が増えるため収益にも直結

| 指標 | 評価 |
|------|------|
| ユーザー価値 | ★★★ |
| 開発コスト | 中 |
| 収益影響 | ◎ |

---

### 2. プロジェクト管理（フォルダ・タグ）

**概要**  
履歴をフォルダやタグで整理できる機能。

**詳細**  
現状は時系列に並ぶだけ。ブランドや案件ごとにフォルダ分け・タグ付けして管理できるようにする。

**期待効果**  
- ヘビーユーザーや企業での利用を想定した機能
- 継続課金のモチベーション向上

| 指標 | 評価 |
|------|------|
| ユーザー価値 | ★★ |
| 開発コスト | 低 |
| 収益影響 | ○ |

---

### 3. テキストオーバーレイ編集（キャプション直接編集）

**概要**  
生成した画像の上にテキスト（キャッチコピー・価格など）をCanva風にドラッグ&ドロップで追加・編集できる機能。

**詳細**  
- フォント・サイズ・カラー・配置の調整
- 生成後のAI編集では難しい細かいテキスト修正を補完

**期待効果**  
- 生成後の微修正ニーズに応え、満足度を向上
- AI編集との相互補完で他サービスとの差別化

| 指標 | 評価 |
|------|------|
| ユーザー価値 | ★★★ |
| 開発コスト | 高 |
| 収益影響 | ○ |

### 4. ブランドキット

**概要**  
ロゴ・ブランドカラー・フォント・よく使うコピーを登録しておける機能。

**詳細**  
- 生成時に自動でブランドの雰囲気に合わせる

**期待効果**  
- 毎回設定し直す手間がなくなり、リテンション（継続利用率）が大幅に向上

### 5. A/Bテスト用複数案提案

**概要**  
同じ設定で意図的に「テイストの違う2〜3案」を一度に生成して並べて比較できる機能。

**詳細**  
- カラー・レイアウト・コピーが異なる複数バリエーションを自動生成
- 各案の簡易的なパフォーマンス予測スコアを表示（将来的に）

**期待効果**  
- 「どのデザインが当たるかわからない」という広告主のニーズに直接応える

| 指標 | 評価 |
|------|------|
| ユーザー価値 | ★★★ |
| 開発コスト | 低 |
| 収益影響 | ○ |
