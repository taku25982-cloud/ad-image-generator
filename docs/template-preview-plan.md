# テンプレートプレビュー画像導入計画書

## 1. 背景と課題
現在、テンプレート一覧画面（`/templates`）には各テンプレートを表現するための画像がなく、カラフルな「グラデーション」と「絵文字（アイコン）」のみが表示されています。
これによりユーザーは「このテンプレートを選ぶと、どのような広告画像が生成されるのか」を視覚的にイメージできず、テンプレート選択の際に迷いが生じています。

## 2. 目的
すべてのテンプレート（現状12種類）に対して、生成される画像のイメージに近い「ダミーのプレビュー画像（プレースホルダー）」を初期データとして当てはめます。
これにより、ユーザーに生成結果のイメージを直感的に伝え、テンプレート選択を容易にすることを目的とします。

## 3. アプローチ（A案：オーソドックスなカード型デザイン）

まずは最も堅実でユーザーに馴染みのある「カード型UI」を採用します。

### 変更前のUI（現在）
- 上部にベタ塗りのグラデーション背景
- 中央に大きく絵文字（🍔や👗など）
- ホバー時のみ「このテンプレートを使う」というテキストが被さる

### 変更後のUI（A案）
- 上部の領域に「具体的な広告イメージ画像」を表示する。
  - 今回はUnsplash（フリー素材API）などの高品質な画像を、テンプレートのカテゴリ（EC、フード、ファッションなど）に合わせて自動で（URLベースで）取得・表示させます。
- グラデーションと絵文字は撤廃、もしくは装飾として小さく隅に残します。
- カードの下半分には引き続きタイトル、説明文、機能タグを表示します。

## 4. 実装プロセス

実装は以下のステップで行います。

### Step 1: テンプレート定義スキーマの更新
`src/lib/templates.ts` 内の `AdTemplate` インターフェースを更新します。
- 既存の `thumbnail` プロパティ（現在はCSSのグラデーション文字列が入っている）を、**画像を表すURL（またはパス）**が入るように再定義します。
- 12種類のすべてのテンプレート定義について、`thumbnail` の値を、そのテンプレートのイメージに合ったUnsplashのプレースホルダーURL（例: `https://images.unsplash.com/photo-1xxx...`）に書き換えます。

### Step 2: テンプレート一覧ページのUI改修
`src/app/templates/page.tsx` を修正します。
- カードの画像表示領域（`<div className="relative h-44...">`）を修正し、`<img>`（または `next/image` の `<Image>` コンポーネント）を用いて、Step 1で設定した画像URLを表示するように変更します。
- 背景画像になじむように、文字やバッジ（🔥 人魚、✨ NEWなど）の可読性を確保するオーバーレイ（半透明の黒いグラデーションなど）を調整します。

### Step 3: 動作確認
ローカル環境等で画面を確認し、各テンプレートの画像が意図したカテゴリ・雰囲気の画像として表示されているか、レイアウト崩れがないかをチェックします。

## 5. 期待される効果
ユーザーが視覚的情報から直感的にテンプレートを選べるようになり、「思ったような画像が生成されない」というギャップを埋めることができます。将来的にはこの静止画をAIが実際に生成したもの（B案）に差し替えることで、さらに精度を高めることが可能です。
