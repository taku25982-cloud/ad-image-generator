# LP強化計画書（参考サイト：サムネAI 調査結果ベース）

> 作成日：2026-03-21  
> 参照サイト：[サムネAI](https://www.samune-ai.jp/)

現在のランディングページ（LP）の訴求力を高め、ユーザーの信頼獲得とCVR（コンバージョン率）向上を実現するためのセクション追加案をまとめます。

---

## 1. 追加セクション案

### ① ユースケース・ギャラリー（「こんな広告画像が作れます」）
*   **内容**: 実際にAIが生成した高品質な画像のサンプルを一覧表示。
*   **表示項目**: 
    *   Instagramストーリー / フィード
    *   YouTubeサムネイル
    *   ECバナー（Amazon/楽天風）
    *   X（Twitter）広告
*   **狙い**: 「本当にこのクオリティの画像ができるのか」というユーザーの懸念を、実例を見せることで即座に解消します。

### ② 課題と解決・Before/After（「制作の苦労をゼロに」）
*   **内容**: 従来の制作方法と、本サービスのフローを比較。
    *   **従来**: 外注費が高い、修正に時間がかかる、デザインスキルが必要。
    *   **本サービス**: 数秒で完成、月額制で作り放題（プランによる）、スキル不要。
*   **狙い**: サービスを導入することによる「時間」と「コスト」の具体的メリットを強調します。

### ③ インタラクティブなAI編集機能（「自動生成のその先へ」）
*   **内容**: 生成後の「プロンプトによる微調整」機能を視覚的に説明。
    *   例：「背景を夜に変更」「文字の色を赤にして」といった指示のデモ。
*   **狙い**: 単なる一発出力ツールではなく、納得いくまで調整できる実用性をアピールし、競合他社との差別化を図ります。

### ④ ユーザーボイス・社会的証明
*   **内容**: クリエイターやマーケター、EC運営者からの口コミ（SNS投稿風のデザイン）。
*   **狙い**: 「他人も使っている」という安心感を与え、心理的なハードルを下げます。

### ⑤ ターゲット属性（「こんな方におすすめ」）
*   **内容**: 
    *   SNSの運用担当者
    *   ECショップオーナー
    *   コストを抑えたい広告代理店
    *   個人事業主
*   **狙い**: 訪問者に「これは自分のためのツールだ」と自分ごと化させます。

---

## 2. 実装の優先順位

| 優先度 | セクション名 | 重要性 | 実装コスト |
| :--- | :--- | :--- | :--- |
| **高** | ① ギャラリー | ★★★ | 中（画像選定が必要） |
| **高** | ③ AI編集の深掘り | ★★★ | 中 |
| **中** | ② 課題と解決 | ★★ | 低 |
| **中** | ⑤ ターゲット属性 | ★★ | 低 |
| **低** | ④ ユーザーボイス | ★★ | 低（実ユーザー増加に合わせて拡充） |

## 3. 次のステップ

1.  **素材準備**: 各フォーマットで「最高品質」のサンプル画像を数枚ずつ生成・選定。
2.  **デザイン定義**: `src/app/page.tsx` の既存デザインシステムに合わせたUIパーツの作成。
3.  **フェーズ実装**: 優先度の高い「ギャラリー」と「AI編集」から順次LPへ統合。
