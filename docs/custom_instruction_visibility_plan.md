# カスタム指示の視認性向上 実装計画

## 概要
ユーザーからの「カスタム指示を全文見れるようにしてほしい」という要望に応えるため、以下の2点を中心に改善を行います。

1. **プレビューサマリーへの追加**: 作成ページの右カラム（設定プレビュー）に、現在入力されているカスタム指示を表示するセクションを追加します。これにより、フォームをスクロールせずとも常に設定内容を確認できるようになります。
2. **情報の全文表示**: 入力エリアの自動高さ調整や、プレビュー欄での「折り返し表示（whitespace-pre-wrap）」を徹底し、長い指示でも途切れることなく確認できるようにします。

## 変更内容

### 1. `src/app/create/page.tsx` の修正
- 設定プレビュー（`設定プレビュー` セクション）の「主なメッセージ」の下に「カスタム指示」セクションを追加します。
- カスタム指示が存在する場合のみ表示し、点線の枠線や薄い背景色（`bg-gray-50`）を使用して、プレミアム感のあるデザインで表示します。
- `whitespace-pre-wrap` を使用し、改行なども保持して全文が表示されるようにします。

### 2. `src/components/ad-config/DynamicFormFields.tsx` の修正
- `TextAreaField` コンポーネントの `textarea` に `resize-y` だけでなく、視認性を高めるための最小高さを確保します。
- 入力欄の `helperText` も、全文確認の重要性を促す表現に微調整します。

## デザイン詳細
- **色**: `gray-50`, `gray-200` (点線), `purple-500` (アイコンなど) を使用し、既存のデザインシステムと調和させます。
- **フォント**: `leading-relaxed` や `text-xs` を使用し、情報量が多くても読みやすさを損なわないようにします。
- **アニメーション**: 追加表示されるセクションには `animate-fade-in` などのマイクロインタラクションを適用し、ユーザー体験を向上させます。

## 検証項目
- [ ] 作成ページでカスタム指示を入力した際、右側のプレビューに即座に反映されるか。
- [ ] 長いテキストを入力しても、プレビュー内で全文が正しく表示されるか。
- [ ] テンプレートを選択した際、テンプレートに含まれるカスタム指示が正しくプレビューに引き継がれ表示されるか。
