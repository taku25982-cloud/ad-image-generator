# Kling AI 動画生成機能の価格設定・クレジット消費案

Kling AI を用いた広告動画生成機能を「AI Generator」に導入する際、持続可能な運営とユーザー体験のバランスを考慮した価格設定（クレジット消費量）を提案します。

## 1. Kling AI の原価・クレジット体系（調査結果）

Kling AI 公式の価格体系（月額プランの場合）と、API/生成時の消費クレジットの目安は以下の通りです。

### Kling AI 公式プラン（月額）
*   **Standard**: $10 (約1,500円) / 660クレジット (1クレジット ≒ 2.27円)
*   **Pro**: $37 (約5,500円) / 3,000クレジット (1クレジット ≒ 1.83円)
*   **Premier**: $92 (約14,000円) / 8,000クレジット (1クレジット ≒ 1.75円)

### 動画生成時の消費クレジット（目安）
*   **標準モード (5秒)**: 約10〜20クレジット（原価：約23〜45円）
*   **プロフェッショナルモード (5秒)**: 約35クレジット（原価：約80円）
*   **プロフェッショナルモード (10秒)**: 約70クレジット（原価：約160円）
*   **高画質化 (Upscale)**: さらに +10〜35クレジットが必要な場合がある。

## 3. 提案：動画生成のクレジット消費量

動画生成は画像生成に比べ演算コスト・APIコストが非常に高いため、以下の消費設定を提案します。

### 案A：シンプルプラン（推奨）
ユーザーに分かりやすく、かつ赤字を回避する設定です。

| 生成内容 | 消費クレジット | 相当金額 (Pro換算) | 備考 |
| :--- | :--- | :--- | :--- |
| **画像生成 (静止画)** | **1 クレジット** | ¥25 | 現行通り |
| **標準動画 (5秒)** | **10 クレジット** | ¥250 | SNS広告の素材用 |
| **高品質動画 (5秒/10秒)** | **25 クレジット** | ¥625 | 商用・プロモード |

### 案B：コスト重視プラン
原価の高い高品質動画をより厳密に設定する場合。

| 生成内容 | 消費クレジット | 備考 |
| :--- | :--- | :--- |
| **標準動画 (5s)** | **15 クレジット** | |
| **Pro動画 (5s)** | **30 クレジット** | |
| **Pro動画 (10s)** | **60 クレジット** | 尺が長いほど消費増 |

## 4. プラン別の利用制限

動画生成機能を全ユーザーに解放すると、Freeユーザー（3クレジット付与）やStarterユーザー（30クレジット）が動画を生成した場合、1〜2回でクレジットが枯渇するか、運営側の赤字リスクが高まります。

### 制限案
*   **Freeプラン**:
    *   動画生成：**利用不可**（プレビューのみ、またはStarter以上への導線）
*   **Starterプラン (30c)**:
    *   標準動画のみ利用可能（月 2〜3 回程度）
*   **Proプラン (80c) 以上**:
    *   高品質動画を含む全機能を利用可能（高品質動画でも月 3 回、標準なら 8 回程度）

---

## 5. 結論と推奨アクション

### 推奨設定
*   **標準動画(5s) = 10クレジット**
*   **高品質動画(10s) = 25クレジット**

この設定により、Proプラン（80クレジット）のユーザーは「画像生成 20枚 + 標準動画 6本」といった柔軟な使い分けが可能になります。
