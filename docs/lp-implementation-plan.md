# LP新セクション実装計画書

「ギャラリー」「AI編集の強み」「ターゲット層」の3つのセクションをLP（`src/app/page.tsx`）に追加するための詳細計画です。

---

## 🏗 実装の全体像

| 追加セクション | 挿入場所 | デザイン形式 | 役割 |
| :--- | :--- | :--- | :--- |
| **① ギャラリー** | ヒーローと「使い方」の間 | カルーセル / ギャラリーグリッド | クオリティへの不安を払拭 |
| **② AI編集の強み** | 「使い方」と「機能」の間 | インタラクティブ・デモ風 | 「修正・微調整」という強みを強調 |
| **③ ターゲット層** | 「機能」と「料金」の間 | 4列カードレイアウト | サービスの「自分ごと化」を促進 |

---

## 🎨 1. 各セクションの詳細設計

### ① ギャラリーセクション（「こんな画像が作成できます」）
*   **レイアウト**: 左右に緩やかに流れる無限カルーセル、または洗練されたMasonryグリッド。
*   **コンテンツ**: 
    *   Instagramストーリー（縦長）
    *   YouTubeサムネイル（16:9）
    *   商品写真（正方形）
    各画像にマウスオーバーで「Fashion / Story」「Food / Square」などのタグを表示。
*   **実装ポイント**: 画像素材には、AIで生成した実用的なサンプル（高品質なもの）を数枚厳選。

### ② AI編集セクション（「言葉で指示するだけの魔法」）
*   **レイアウト**: 2カラム（左：Before/After画像、右：説明＋チャット風プロンプト）。
*   **インタラクション**: 
    *   「背景を夜に」「文字をゴールドに」といった指示がチャットバブルで表示され、それに応じて画像が切り替わる（またはフェード）アニメーション。
*   **実装ポイント**: スライダー形式（Before/After）を導入し、手動で変化を確認できるようにする。

### ③ ターゲットユーザー属性（「あなたのビジネスに」）
*   **レイアウト**: 4つのアイコンカード。
    *   **SNSマーケター**: 「投稿の反応率を最大化」
    *   **ECショップオーナー**: 「商品写真を即時にバナーへ」
    *   **広告代理店**: 「構成案作成の時間を1/10に」
    *   **個人事業主**: 「デザイナーなしでプロの仕上がり」
*   **実装ポイント**: モバイルでは2列に折り返し、タッチしやすいサイズを確保。

## 🛠 2. 開発ステップ

### Step 1: 素材の準備・生成
*   [ ] `generate_image` ツールを使用して、LPに掲載する最高品質のサンプル画像を各フォーマット分（計6〜8枚程度）生成。
*   [ ] Before/After比較用のペア画像を1〜2セット作成。

### Step 2: UIコンポーネントの構築
*   [ ] `GallerySection.tsx`（仮称）: カルーセル/グリッドの基本構造。
*   [ ] `AIEditorShowcase.tsx`（仮称）: Before/Afterスライダーとプロンプトアニメーション。
*   [ ] `TargetUsersSection.tsx`（仮称）: 4項目のアイコンカード。

### Step 3: `page.tsx` への統合とスタイル調整
*   [ ] セクション間の余白、グラデーションの繋がりを調整。
*   [ ] モバイル表示時のフォントサイズやレイアウト最適化。
*   [ ] スクロールに合わせたフェードイン（Intersection Observer / Tailwind Animate）の適用。
