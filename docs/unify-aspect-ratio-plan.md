# アスペクト比16:9統一化計画書

## 背景
すべての広告画像テンプレートプロンプトのアスペクト比を16:9に統一する。

## 目的
- プロダクト全体で画像アスペクト比を16:9に揃え、一貫性を確保する。
- ターゲットサイズを `1920x1080px` に統一する。

## 作業内容
### 1. ファイルの修正
対象ファイル: `docs/flow-template-prompts-expanded.md`
以下の項目の置換を行う：
- サイズ指定（1080x1920, 1080x1080, 1200x628, 300x250）→ `1920x1080`
- フォーマット指定（instagram-story, instagram-feed, facebook-ad, google-display）→ `landscape-16-9`
- 日本語でのアスペクト比、形状、掲載面の言及を `16:9の横長広告` や `16:9横長` に変更。

### 2. 変更の確認
- `grep`（または `Select-String`）を使用して、旧サイズや旧形式の言及が残っていないか確認する。
- 書き換え後の内容が不自然（重複など）になっていないか、主要な箇所を目視でチェックする。
